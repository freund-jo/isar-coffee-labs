# Lab 1 · Eval

Isar Coffee has a small AI assistant that answers price questions. It works – mostly.
You build an eval for it, find out where it goes wrong, fix it, and add an LLM judge for
answers that no simple check can grade.

**Time:** about 60 minutes, planned with 90. Whatever is left over is homework.
**Cost:** a few cents (Claude Haiku).

**How to start:** do the setup in the [main README](../README.md) once, then open
`Eval.ipynb`, pick the kernel **Isar Coffee Labs (.venv)** and run the cells from the top.

| File | What it is |
|---|---|
| `Eval.ipynb` | The lab – work in this one |
| `Eval.py` | The same lab as a plain Python file. The notebook is generated from it |
| `CLAUDE.md` | Notes for the Claude tutor |
