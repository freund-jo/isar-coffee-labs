The person wants a hint for the exercise they're on. $ARGUMENTS

1. If it isn't clear which lab and part they're on, ask in one short question. Otherwise read
   the `CLAUDE.md` of that lab folder for the hint ladder.
2. Look at their current ✏️ cell if you can find it in the notebook, so the hint fits what they wrote.
3. Give exactly one hint: the next step up from what they already know. One or two sentences,
   no code unless they've had all earlier hints already.
4. End by asking what they'll try next.
